# 行业级 Agent 趋势判断：运行输出与安全

> 本文档拆自 [行业级Agent趋势判断设计文档.md](../行业级Agent趋势判断设计文档.md)，是行业级 Agent 趋势判断设计文档包的一部分。

## 日级与周级运行口径

### Daily

Daily 可以生成行业证据包，但不做最终行业趋势裁决。

```text
specialized agents / tools
  -> IndustrySignalEvent[]
  -> normalization-agent
  -> DailyIndustryEvidencePack
  -> run-summary / verify audit
```

`DailyIndustryEvidencePack`：

```ts
interface DailyIndustryEvidencePack {
  schema_version: "daily-industry-evidence-pack.v1";
  date: string;
  generated_at: string;
  agent_contributions: IndustryAgentContribution[];
  accepted_events: IndustrySignalEvent[];
  rejected_events: IndustrySignalEvent[];
  registry_snapshot_ref: string;
  tool_registry_snapshot_ref: string;
  public_safe: boolean;
  coverage_summary: Record<IndustryEvidenceAxisKey, {
    status: "covered" | "partial" | "missing" | "failed" | "unavailable";
    accepted_event_count: number;
    counter_event_count: number;
    missing_reason_codes: string[];
  }>;
}
```

`DailyIndustryEvidencePack` 字段定义冻结如下：

| 字段 | 类型 / 取值 | 含义 | 执行约束 |
| --- | --- | --- | --- |
| `date` | `YYYY-MM-DD` | daily evidence pack 所属日期。 | 必须按 Asia/Shanghai 运行日解释，不能混用 UTC 日期。 |
| `generated_at` | ISO datetime | 证据包生成时间。 | 用于审计，不得替代事件发布时间。 |
| `agent_contributions` | `IndustryAgentContribution[]` | 当日各职责项贡献账本。 | 必须覆盖 15 个职责项。 |
| `accepted_events` | `IndustrySignalEvent[]` | 当日被接受的行业事件。 | 只能包含 public-safe 且通过归一/gate 的事件。 |
| `rejected_events` | `IndustrySignalEvent[]` | 当日被拒绝或只作审计的事件。 | rejected 不得参与评分，但必须保留原因。 |
| `registry_snapshot_ref` / `tool_registry_snapshot_ref` | string | 当日使用的 registry 快照。 | weekly 合并时必须记录快照差异或 stale 状态。 |
| `public_safe` | boolean | daily pack 是否可进入公开产物。 | false 时 weekly 不得消费其中 raw-sensitive 内容。 |
| `coverage_summary[axis].status` | `covered` / `partial` / `missing` / `failed` / `unavailable` | 当日该轴覆盖状态。 | `covered` 不等于 strong；只表示该轴有可用采集覆盖。 |
| `accepted_event_count` / `counter_event_count` | number | 当日该轴 accepted / counter 数。 | 必须与 accepted_events 中 axis 计数一致。 |
| `missing_reason_codes` | string[] | 缺失原因。 | `partial/missing/failed/unavailable` 时不能为空。 |

### Weekly

Weekly 读取最近 7 日 `DailyIndustryEvidencePack[]`、现有 project weekly artifacts 和 `DailyExternalAggregate[]`，再做行业主张裁决。

```text
DailyIndustryEvidencePack[7d]
  + DailyExternalAggregate[7d]
  + WeeklyEvidenceProject[]
  + observer / mission discovery summaries
  -> IndustryClaimLedger[]
  -> Weekly industry output
```

规则：

1. weekly 不直接读取 provider raw input。
2. daily industry pack 缺失不阻断主 weekly，但必须在行业层标注 `industry_evidence_window_status=partial / missing`。
3. 如果行业层完全不可用，weekly 回退到现有项目级趋势判断，并显式写出 `行业证据不足，本周仅提供项目级趋势回退判断`。
4. `run-weekly --dry-run` 只能报告计划读取的 industry pack、external aggregate 和 weekly writes，不写入新产物。

## Weekly 输出契约

`WeeklyReport` 后续应新增行业层字段，同时保留现有兼容字段。

```ts
interface WeeklyIndustryTrendSection {
  industry_window_status: {
    status: "ok" | "partial" | "missing" | "failed";
    usable_day_count: number;
    missing_day_count: number;
    notes_cn: string[];
  };
  industry_summary_cn: string;
  core_industry_trends: IndustryTrendCard[];
  observing_industry_trends: IndustryTrendCard[];
  wind_probes: IndustryTrendCard[];
  project_heat_clusters: IndustryTrendCard[];
  insufficient_evidence_directions: IndustryTrendCard[];
  agent_contribution_report: IndustryAgentContribution[];
  tool_coverage_report: AxisToolCoverageReport[];
}

interface IndustryTrendCard {
  claim_id: string;
  trend_name_cn: string;
  claim_cn: string;
  decision_tier: IndustryTrendDecision["decision_tier"];
  decision_reason_cn: string;
  evidence_matrix: AxisEvidenceSummary[];
  leading_axes: IndustryEvidenceAxisKey[];
  supporting_axes: IndustryEvidenceAxisKey[];
  missing_axes: IndustryEvidenceAxisKey[];
  counter_axes: IndustryEvidenceAxisKey[];
  project_landing_samples: Array<{
    repo_url: string;
    repo_full_name: string;
    role: "landing_sample" | "open_source_signal" | "project_heat_only";
  }>;
  what_to_watch_next_week_cn: string;
  source_trace_refs: string[];
}
```

`WeeklyIndustryTrendSection` 字段定义冻结如下：

| 字段 | 类型 / 取值 | 含义 | 执行约束 |
| --- | --- | --- | --- |
| `industry_window_status.status` | `ok` / `partial` / `missing` / `failed` | 7 日行业证据窗口状态。 | `partial/missing/failed` 必须影响卡片 confidence 或显示降级说明。 |
| `usable_day_count` / `missing_day_count` | number | 可用 / 缺失 daily pack 天数。 | 两者加总不得超过窗口天数；异常必须在 notes 中说明。 |
| `industry_summary_cn` | string | 行业层总摘要。 | 不得引入未在 cards / ledgers 中出现的新事实。 |
| `core_industry_trends` / `observing_industry_trends` / `wind_probes` / `project_heat_clusters` / `insufficient_evidence_directions` | `IndustryTrendCard[]` | 五个用户可见分区。 | 卡片必须放入与 `decision_tier` 对应的唯一分区，不得重复出现。 |
| `agent_contribution_report` | `IndustryAgentContribution[]` | weekly 汇总 Agent 贡献。 | 必须覆盖 15 个职责项，不能只展示成功项。 |
| `tool_coverage_report` | `AxisToolCoverageReport[]` | weekly 工具覆盖账本。 | 必须覆盖十个 evidence axis。 |

`IndustryTrendCard` 字段定义冻结如下：

| 字段 | 类型 / 取值 | 含义 | 执行约束 |
| --- | --- | --- | --- |
| `claim_id` | string | 对应 `IndustryClaim.claim_id`。 | 必须能反查 `IndustryClaimLedger`。 |
| `trend_name_cn` / `claim_cn` | string | 用户可读名称和主张。 | 名称不能夸大等级；风向探针必须使用可能性语气。 |
| `decision_tier` | `IndustryTrendDecision.decision_tier` | 卡片等级。 | 必须与所在分区一致。 |
| `decision_reason_cn` | string | 裁决理由。 | 必须与 ledger decision reason 一致或是其摘要。 |
| `evidence_matrix` | `AxisEvidenceSummary[]` | 十轴证据矩阵。 | 必须包含十个 axis，缺失也要显式 `missing/unavailable`。 |
| `leading_axes` / `supporting_axes` / `missing_axes` / `counter_axes` | `IndustryEvidenceAxisKey[]` | 卡片级轴分类。 | 必须与 decision 和 evidence_matrix 对齐。 |
| `project_landing_samples` | object[] | 项目落地样本。 | `project_heat_only` 不能被写成行业落地验证。 |
| `what_to_watch_next_week_cn` | string | 下周观察点。 | 必须来自 missing/counter/early signal，不得凭空新增任务。 |
| `source_trace_refs` | string[] | 下钻追溯引用。 | 必须能追溯到 event、source、agent 或 tool route。 |

展示规则：

- 核心行业趋势位于 weekly 主叙事。
- 观察中趋势和风向探针在核心趋势之后。
- 项目热度簇必须与行业趋势分区，不得混在核心趋势卡里。
- 证据不足方向不隐藏，必须进入缺口账本。
- 每张卡的十轴矩阵必须可下钻到 event、source、agent 和 tool route。

## 失败、降级与安全

| 失败模式 | 状态 | 处理 |
| --- | --- | --- |
| 某专责 Agent 缺失或未配置 | `agent_contribution.status=unavailable` | 对应轴最高只能为 `unavailable / missing`，不得伪装已覆盖 |
| primary tool 失败但备用可用 | `tool_route_state.active_route_level=secondary_toolset/fallback_tools` | 继续使用备用证据，并标注降级来源 |
| 全部工具链失败 | `axis.status=unavailable` | weekly 显示该轴未参与判断，不得写成无趋势 |
| registry 缺失或 stale | `registry_status=failed/stale` | 该主体不能作为 `core/proven`，阻断核心趋势升级 |
| 外部 Agent 输出 schema 非法 | rejected | 保留 rejected event 和原因，不进入评分 |
| 资本/政策/新闻主导但无落地交叉确认 | downgrade | 最多进入 `wind_probe`，不得进入核心行业趋势 |
| 高权威反证出现 | countered | 降级为观察/证据不足，保留历史证据链 |
| 非 repo 证据无法绑定项目 | direction evidence | 仍可进入方向级主张，不强行绑定 repo |
| public-safe 验证失败 | failed | 不得提交公开 artifact，不得被 weekly 消费 |
| 行业层完全失败 | industry fallback | 主 weekly 继续，以项目级趋势回退，并显示行业证据不足 |

Public-safe 边界：

- 不提交 cookie、session、OAuth、账号配置、平台 API 凭据、私有 diagnostics。
- 不提交 raw social text、profile URL、未脱敏 handle，除非已通过 public-safe fixture 规则。
- `data/raw/industry-intelligence/` 若存在，只能作为 local-only raw input，默认不进入公开历史。
- 公开消费产物必须包含 `public_safe=true`、`redaction_policy_version`、`contains_raw_text=false`、`contains_profile_urls=false`。

## 产物目录建议

```text
data/industry-intelligence/
  registry/
    entities.json
    tools.json
    source-state.json
  daily/
    YYYY-MM-DD.evidence-pack.json
  messages/
    YYYY-MM-DD.messages.jsonl
    YYYY-MM-DD.artifact-manifest.jsonl
  weekly/
    YYYY-MM-DD.claim-ledger.json
    YYYY-MM-DD.agent-contributions.json
    latest.json

data/raw/industry-intelligence/
  # local-only raw provider drops; default not committed

eval/industry-intelligence/
  gold-industry-claims.jsonl
  negative-industry-signals.jsonl
  replay-windows/
    YYYY-MM-DD.input-manifest.json
    YYYY-MM-DD.expected-ledger.json
```

`entities.json`、`tools.json`、`daily/*.evidence-pack.json`、`messages/*.messages.jsonl`、`messages/*.artifact-manifest.jsonl` 和 `weekly/*.claim-ledger.json` 是 canonical artifact。任何 visual console 或 Web surface 只能读取这些 artifact，不得在前端重新推导趋势等级。
