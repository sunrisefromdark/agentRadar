## 目标

把客户端交互拆成 hydration、route state、events、shared hooks/components 和 route 页面目录。React 大页面按 route 分层，`clientScript.ts` 逐步收缩为启动壳。

## 目标目录形态

```text
app/visualConsole/hydration/
  boot.ts
  dom.ts
  events.ts
  routeState.ts
  persistence.ts

app/client/
  shared/
    components/
    hooks/
    state/
  routes/
    weekly/
      WeeklyView.tsx
      weeklyState.ts
      weeklyFilters.ts
    observer/
    run-health/
    projects/
```

## 不变量

- 客户端不得重新计算 score、weekly trend、observer ranking。
- SSR 内容在 JS 失败时仍可读。
- DOM selector 和 data attribute 合同不随意改名。
- 不引入新的前端状态库。

## 回滚策略

按交互点和 route 回滚。某 handler 新路径失败时，旧 `clientScript.ts` handler 继续接管，失败样本进入对应 route 测试。
