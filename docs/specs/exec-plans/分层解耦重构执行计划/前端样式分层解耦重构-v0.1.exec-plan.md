## 目标

把样式从一个全局巨型文件拆成可归属、可审核、可逐步迁移的样式层。先新建分层目录并保留旧入口，再按基础层、组件层、路由层迁移，最后删除旧重复选择器。

## 不变量

- 不改变现有 HTML / React class 合同。
- 不改变视觉层级、主题 token、响应式断点语义。
- 不把 CSS 迁移成组件内联 style。
- 不引入 CSS framework 或新的构建插件。
